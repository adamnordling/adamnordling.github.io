Privacy Policy & Architecture

Data Collection & Cookies

This portfolio website is engineered with a strict privacy-first architecture. It collects zero personal data, operates with zero tracking or session cookies, and embeds no analytics, marketing, or advertising telemetry scripts.

Client-Side Utility Execution

All computational tools, cryptographic hashers, and data converters execute 100% client-side inside your browser's local sandbox. No input content, files, or parameters are transmitted to any backend server.

External Network Dependencies

Third-party interactions are strictly confined to:

1. Anonymous read-only calls to the public GitHub API to render recent open-source commits.
2. Encrypted asset delivery through Cloudflare's edge CDN.
